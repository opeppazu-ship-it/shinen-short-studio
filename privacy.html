2. 利用する情報と目的

情報内容と利用目的
動画の制作情報入力テーマ、台本、最近の台本の一部、音声、字幕、画像素材、完成動画。台本生成、内容の重複軽減、映像制作、プレビューに使います。
API・認証情報Gemini APIキー、Google OAuthクライアント設定、アクセストークン・更新トークン。各APIへの接続に使います。GoogleのパスワードはGoogleの認証画面で扱い、本アプリでは保存しません。
チャンネル・投稿情報認証したチャンネルのIDと名前、投稿した動画のID・リンク、投稿処理の記録。接続先確認、動画のアップロード、重複投稿の防止に使います。
YouTube分析情報視聴回数、エンゲージビュー、平均視聴率・時間、登録者増加、高評価、共有、取得可能な視聴維持の集計指標。自分の動画の結果の確認と、アプリ独自の振り返りに使います。個々の視聴者の氏名やメールアドレスを取得する機能はありません。
設定・処理ログ制作や自動実行の設定、処理結果、エラーなど。動作確認と不具合の調査に使い、PC内に保存します。

本アプリはYouTube API Servicesを使用します。利用にはYouTube利用規約が適用され、Googleによる処理はGoogleプライバシーポリシーに従います。

3. 外部サービスへの送信

Claude：台本の 読みやすさの 確認（ONのとき）

設定で ON にしたときだけ、Gemini が作った台本の文（タイトル・説明・セリフ）と テーマを、Anthropic の Claude API へ送り、読みやすさと 表現の 確認をします。送るのは 台本の 文だけで、YouTube の ログイン情報や 動画ファイル、APIキーの 中身は 送りません。Anthropic の 取り扱いは Anthropic のプライバシーポリシー を ご覧ください。

Gemini：通常の台本生成

入力テーマ、制作指示、最近の台本のタイトルや出だしなど、生成に必要な参考情報をGoogleのGemini APIへ送信します。生成後の安全確認で、台本の内容を追加送信する場合があります。利用者がテーマや参考情報に入力した内容も送信対象です。

Geminiの無償サービスでは、入力と出力がGoogleのサービス・機械学習技術の改善などに使われ、人による確認の対象になることがあります。機密情報、個人情報、非公開の分析データを通常の入力に含めないでください。利用するプランや地域による条件はGemini APIの追加利用規約をご確認ください。

YouTube分析の要約：任意の共有

アプリが分析から作るメモには、動画のテーマ、出だし、長さ、再生数、平均視聴率などが含まれます。このメモをGeminiへ自動送信するには、「設定」で次の両方を有効にする必要があります。

  1. Gemini APIの有料サービスを利用し、入力がモデル改善に使われない条件を確認する。
  2. YouTube分析の要約をGeminiへ送って、台本の改善に使うことに同意する。

両方とも初期設定はオフです。この確認操作で課金を有効にすることはありません。本アプリは契約や請求状態を自動判定しないため、利用者が確認してください。有料サービスにも不正利用の検出などを目的とする一定の保持があり、詳細はGemini APIの有料サービス条件に従います。

共有前にはGoogleの認証情報を更新して現在のアクセス権を確認します。確認が失敗した場合やオフラインの場合、分析メモは自動送信しません。共有をオフにすると、以後の自動送信を止めます。すでにGoogleへ送った情報や、その情報を参考に生成した台本を取り戻したり、自動削除したりする機能はありません。

YouTubeへの投稿・読み取り

投稿時は動画、タイトル、説明、公開範囲、子ども向け設定などをYouTubeへ送信します。チャンネル確認と分析では、本人が許可したアカウントの情報をGoogleから取得します。認証には動画アップロード、チャンネル等の読み取り、YouTube Analyticsの読み取りの権限を使用します。

音声・背景の制作

VOICEVOXには読み上げるテキスト等、ComfyUIには背景の生成指示等を、アプリで設定した接続先へ送信します。初期設定はPC内のサービスです。外部サーバーに変更する場合は、その提供者の取り扱いを確認してください。

本アプリには、制作物やYouTube分析データを運営者のサーバーへ収集する機能、広告配信や販売のために共有する機能はありません。利用者が問い合わせメールに記載した情報は、対応のため運営者が受け取ります。

4. 保存場所と保存期間

アプリが管理する情報は、利用者のPCのアプリフォルダに保存します。クラウド同期対象のフォルダやバックアップ先を利用者が選んだ場合、そのサービスにもコピーされることがあります。

対象保存と更新・削除
分析指標取得日時から30日で期限切れにします。アプリの起動時や分析データの読み取り・更新時に古い指標を削除し、関連指標のなくなった分析用メタデータも削除します。分析は投稿から48時間〜30日の動画が対象で、再取得は前回から24時間以上空けます。
振り返りメモ作成から7日、または元になった指標の保存期限の、早い方まで保持します。元のデータが削除された場合もキャッシュを無効にします。
チャンネル確認画面からの投稿ではAPIで現在のチャンネルを確認します。古いキャッシュを投稿先確認の代わりに使いません。
認証・投稿記録認証トークンは接続を維持するため保存します。動画ID・投稿リンクと処理ログは、接続解除や保存YouTubeデータの削除などで対象を消すまで残ります。分析指標の30日期限とは異なります。
生成した制作物動画、台本、素材などは、利用者が削除するまで残します。YouTubeデータの削除や接続解除では消しません。

PCやアプリが停止している間は、削除処理を実行できません。期限を過ぎていても、次回起動・データ利用時に清掃します。アプリを使わなくなる場合は、終了前に接続解除やデータ削除を行ってください。

APIキー、OAuth設定、認証トークンはローカルのファイルに保存し、アプリ独自の暗号化はしていません。アプリフォルダを公開・共有しないでください。PCのアカウント保護やディスク暗号化、バックアップの管理は利用者側で行ってください。

5. 接続の解除とデータの削除

「YouTubeの接続を解除」

アプリの「設定」から実行できます。Googleの公式の取り消し処理が成功した場合、またはトークンがすでに無効と確認された場合に、このPCの認証トークンとアプリ管理下のYouTubeデータを削除し、分析共有の同意をオフにします。Googleとの通信や取り消しが失敗した場合は、再試行できるようローカルの情報を保持し、エラーを表示します。

Google側の取り消し後でも、ファイルの使用中や書き込み権限の問題でローカル削除が完了しない場合があります。エラーが表示されたときは、他の処理を止めて再実行してください。認証の更新時に明確な失効を検知した場合も、ローカルの認証・YouTubeデータを削除する処理を行います。

「保存したYouTubeデータを削除」

アプリ管理下の分析データ、振り返りメモ、チャンネル情報の保存ファイル、投稿ID・リンクなどの投稿記録を削除し、アプリの所定の処理ログからYouTube関連の行を除去します。認証トークンは残るので、Googleへの接続は継続します。分析を再実行するとデータを再取得することがあります。重複投稿を防ぐため、IDやリンクを含まない「投稿済み」の印を残します。

Google側で取り消す場合

Googleアカウントの接続管理画面から本アプリのアクセス権を取り消せます。Google側での操作だけでPC内のファイルが直ちに消えるわけではありません。アプリでも接続解除を実行するか、認証の失効検知後の清掃結果を確認してください。

削除されないもの

生成した動画・台本・素材、Geminiの設定、OAuthクライアント設定ファイル、利用者が別の場所へコピーしたファイル、クラウド同期・バックアップ・ごみ箱の内容は対象外です。YouTube上に投稿した動画も削除しません。公開済み・非公開の動画はYouTube Studioで管理してください。Googleなど外部サービスへ送信済みの情報には、各サービスの保存・削除条件が適用されます。
