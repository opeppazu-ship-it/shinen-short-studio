WINDOWS · SHORT VIDEO STUDIO

一般配布前のローカル試用版

テーマから、
短い物語を。

台本、音声、字幕、縦型映像。
ショート動画づくりの工程を、ひとつのアプリにまとめました。できあがった作品を見てから、次の一歩へ。

できることを見るデータの取り扱い
  1. テーマを決める作りたい物語をひとことから
  2. 台本と映像を作る音声・立ち絵・字幕を合成
  3. 動画を確認するPCに保存してプレビュー
  4. 必要ならYouTubeへ接続先と投稿内容を確認

CREATE AT YOUR PACE

制作から振り返りまで

01 / つくる

掛け合いのある縦動画

Geminiで台本を生成し、VOICEVOXの音声、立ち絵、背景、字幕を組み合わせます。完成動画はPCに保存します。

02 / たしかめる

見てから投稿を決める

画面からの投稿では、接続先チャンネル、タイトル、説明、公開範囲、子ども向け設定を確認して送信します。

03 / ふりかえる

自分の動画の結果を読む

YouTubeの再生数や視聴維持の指標を取得し、制作の参考にします。アプリ独自の振り返りは、YouTube公式の評価ではありません。

YouTube連携は、必要なときに。

このアプリは YouTube API Services を使用します。Googleの認証画面で許可したチャンネルへの動画投稿、投稿先の確認、分析情報の読み取りに利用します。Googleのパスワードをアプリに保存することはありません。

分析結果はPC内に保存します。分析の要約をGeminiへ送る機能は初期設定でオフです。有料サービスのデータ保護条件の確認と、別途の共有同意がそろった場合にだけ、自動送信を有効にできます。

「設定」から接続解除や保存データの削除ができます。手順と対象はプライバシーポリシーをご確認ください。

予約・自動モードを利用する場合は、その設定に従って制作や非公開投稿が実行されます。有効にする前に、接続先と設定を確認してください。

現在の提供状況

Windows PCで利用する、動画制作者向けの開発・試用段階のアプリです。一般向けの配布はまだ開始していません。このページからアプリをダウンロードすることはできません。

外部APIの利用枠や認証、審査状況によって、YouTube連携などの機能を使えないことがあります。本ページの掲載は、Googleによる審査完了や認定を示すものではありません。

利用前に利用条件とプライバシーポリシーをご確認ください。
